# Features

## Authentication

Allows users to create accounts and securely log into the application.

## Emergency Contacts

Users can store trusted contacts who will receive emergency alerts.

## Fake Call Generator

Allows users to schedule a fake incoming call to leave uncomfortable situations.

## Fake Message Generator

Allows users to receive a fake message notification as an excuse to exit a situation.

## SOS Alert

Sends an emergency notification along with location information.

## Safety Timer

Tracks expected travel time and sends alerts if the user does not confirm safety.
