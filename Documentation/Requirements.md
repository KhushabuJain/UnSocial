\# UnSocial Requirements



\## Project Goal



UnSocial is a web application that helps users discreetly exit uncomfortable social situations and provides personal safety features during emergencies.



\## User Roles



\### User



\* Register account

\* Login account

\* Manage profile

\* Manage emergency contacts



\## Features



\### Authentication



\* User Registration

\* User Login

\* Logout

\* Password Encryption



\### Emergency Contacts



\* Add Contact

\* Edit Contact

\* Delete Contact

\* View Contacts



\### Fake Call Generator



\* Create Fake Call

\* Set Caller Name

\* Set Delay Time



\### Fake Message Generator



\* Create Fake Message

\* Set Sender Name

\* Set Delay Time



\### SOS Alert



\* Send Emergency Alert

\* Share Current Location

\* Save SOS History



\### Safety Timer



\* Start Timer

\* Stop Timer

\* Trigger Alert if Timer Expires



\### Dashboard



\* View User Information

\* View Recent Activity

\* Quick Access to Features
